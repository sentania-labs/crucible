# C10: authenticated lab-local gateway

## Delivered behavior

- The lab CA is committed at `images/ca/sentania-lab-root.crt`, pinned by raw-file
  SHA-256 `567f110bb80bb2179b44995c78c7a49a4149085a59f6acb73cf37c6503a0481a`, and
  installed in every worker image. The three standard certificate-bundle variables
  point at the merged system bundle.
- Hermes declares optional read-only credential file `api-key`. A configured key is
  mapped to `OPENAI_API_KEY` from the mounted file and is never synced back. Without a
  configured source, the explicit `local-no-auth` placeholder preserves compatibility
  with unauthenticated OpenAI-compatible endpoints.
- The migration creates the next free immutable routing version, version 6 on an
  unmodified database, removes the `gpt-oss:120b` pin, and creates disabled model `coder`
  in pool `lab-local`. The operator can edit the endpoint URL, model enablement,
  thinking preference, and pool concurrency in the UI, API, or CLI. Each save creates
  new immutable routing and delivery policy versions and regenerates the Docker proxy
  configuration. The active proxy file lives in a named volume writable by the app;
  atomic replacement signals the running Squid process to validate and reload it.
- The Hermes key paste writes one mode-0600 file atomically. It returns no key, logs no
  key, and emits only the `credential_set` audit event. Validation checks readiness
  without authentication before checking `/v1/models` with the bearer.
- Docker and Kubernetes resolve the configured gateway hostname to exact destination
  addresses and keep the configured port exact. Kubernetes refuses a local endpoint
  URL that directly names an API, namespace, node, link-local, or other denied address.

## Environment and recovery

`CRUCIBLE_LOCAL_ENDPOINT_URL` is only a first-migration seed. The old
`CRUCIBLE_SPARK_ENDPOINT_URL` name remains a compatibility seed. Once routing version 6
exists, the active database policy is authoritative and a restart cannot overwrite it
from either environment value.

Recovery is bounded and reversible: disable `coder` or select the preceding immutable
policy version. The save regenerates and reloads the proxy configuration. Key
replacement uses the same paste operation. The previous policy documents remain in the
database, and no public DNS operation is part of this path.

## Hermes thinking limitation

Hermes 0.19.0 does not expose a safe non-interactive CLI option for passing
`chat_template_kwargs.enable_thinking` on each run. C10 stores the operator's choice in
the routing entry so it survives policy versioning, but does not claim that the current
Hermes transport sent it to the gateway. This is a retained intent field until the
adapter gains a supported transport.

## Issue 57

The Kubernetes local-endpoint exception now uses only the configured, resolved gateway
hostname and port. A private result must also fit the operator-declared
`local_endpoint_cidrs`; the base carries an empty list and the lab overlay's
`REPLACE_ME_LOCAL_ENDPOINT_CIDRS` placeholder sets the one address lab-admin allows. A
direct denied IP, the API Service address, or another namespace address is refused
before a NetworkPolicy is created. This closes the bypass described by issue 57 without
broadening the general hostname allowlist.
